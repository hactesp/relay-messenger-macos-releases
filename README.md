# Relay

A native macOS app for Messenger, written in Swift. Independent project, not affiliated with Meta.

## Download

Get the latest build from [Releases](../../releases/latest): `Relay-<version>-macOS-universal.zip` (Apple silicon + Intel, macOS 13 or later).

## Install

1. Unzip and drag `Relay.app` to `/Applications`.
2. The build is not notarized yet, so on first launch right-click the app and choose **Open**.
